# CodeAlpha Random Quote Generator

A simple and responsive Random Quote Generator developed as part of the CodeAlpha App Development Internship.

## Features

- Random quote displayed when the application opens
- Generate a new random quote
- Display quote author
- Copy quote to clipboard
- Responsive design
- Clean and minimal user interface

## Technologies Used

- React.js
- Vite
- JavaScript
- CSS3

## How to Run

```bash
npm install
npm run dev
